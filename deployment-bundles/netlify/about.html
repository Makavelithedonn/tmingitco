About rgosuksa

This is a structural replica of rgosuksa.com built with Cloudflare Workers, KV storage, and D1 database for OTP and card management.

Features

  • OTP-based authentication (5-minute expiry via KV)
  • Card storage with HMAC-hashed phone numbers (D1)
  • Rate limiting per IP address
  • SMS provider support (Twilio, Vonage, or mock)
  • Fully responsive design for mobile, tablet, and desktop

Technology

  • Frontend: HTML, CSS (responsive), vanilla JavaScript
  • Backend: Cloudflare Workers (serverless)
  • Storage: Cloudflare KV (OTP, rate-limit state), D1 (card records)
  • Security: HMAC phone hashing, parameterized queries, rate limiting
